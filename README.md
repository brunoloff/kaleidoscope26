# Kaleidoscope'26

Web materials for the Kaleidoscope'26 complexity workshop.

## Group photo

The current home page is the interactive workshop group photograph.

The site is plain HTML, CSS, SVG, and JavaScript, with no build step or external dependencies. GitHub Pages serves `index.html` directly from the `main` branch.

The photograph and participant details are published for the workshop website. No reuse license is granted.
